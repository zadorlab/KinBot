# CH3SS R8 scouting

Use [input.json](input.json) with the ordinary KinBot PES driver.
The shared [staging and launch instructions](../../ch3s_anl1_f12/scouting_r8/README.md)
cover both CH3S and CH3SS with one 20-job pool.

This is B3LYP-D3(BJ)/cc-pVDZ -> B2PLYP-D3(BJ)/cc-pVTZ -> MESS/PST.
ANL and rotdPy are disabled. MESS inputs are written automatically; rates are
run and screened afterward. The production input and orbital evidence in the
parent example directory are retained for R9.
